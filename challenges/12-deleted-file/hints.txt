Work in three terminals. Terminal 1: `tail -f /tmp/lab12.log`.
Terminal 2: `rm /tmp/lab12.log`. Watch terminal 1 keep printing.
---
The program is still running and still holding the file open. Find
its number:

    cat /opt/lab/openfile/writer.pid
---
Every process has a folder of the files it currently has open:

    ls -l /proc/<pid>/fd

One entry points at your deleted log -- it will say `(deleted)`.
That link still works.
---
Copy the still-open file back out through that link:

    pid=$(cat /opt/lab/openfile/writer.pid)
    cp /proc/$pid/fd/1 ~/recovered.log
    tail ~/recovered.log

Check the number -- it may not be `1`. `ls -l /proc/$pid/fd` shows
which entry points at `lab12.log (deleted)`.
