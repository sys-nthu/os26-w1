`ls -ld /opt/lab/ch09/project` -- the folder is already in group
`team`. The files created inside it are not inheriting that.
---
There is a bit you can set on a folder that means: "anything
created in here takes *my* group, not the creator's group."

It is a cousin of the `t` bit from challenge 7, and it is set the
same way -- a fourth digit in front.
---
Challenge 7 used `1` for the fourth digit. This one is `2`.

Keep the folder's existing `775`.
---
    sudo chmod 2775 /opt/lab/ch09/project

You can also write `sudo chmod g+s /opt/lab/ch09/project`.

`ls -ld` now shows `drwxrwsr-x` -- an `s` where the group's `x`
used to be. Try the two `touch` commands again and look at the
group column.
